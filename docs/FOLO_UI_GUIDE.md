# 动物森友会服务台 UI 源码版

适用设备：Folo AI Passport，ESP32-C3，8MB Flash，无 PSRAM，240 × 320 ST7789P3。

## 这次已修改什么

- 主人公改为动物森友会西施惠形象，作为 240 × 320 全屏背景铺满屏幕，取代原来的代码绘制像素人物。
- 背景图为 RGB565 预转换图片（`bg_shizue.c`），直接从 flash 渲染，无 PSRAM 也不占运行内存。
- 对话文字下方常显一张带透明的气泡背景（`bubble_bg.c`，RGB565A8）；系统文案和对话都渲染在气泡内。
- 回复文字支持多行自动换行，并底部对齐：内容超出气泡高度时，最早的行向上滚出顶部消失，新内容从底部追加。
- 运行期以 50% 音量循环播放 `Resident.mp3`（离线转码为 `resident.ogg`，增益烘焙进文件）作为背景音；说话、聆听、通知、连接、配网、激活、升级时自动让路，仅待机时播放，不影响回复音量。
- 顶部显示网络、静音、同步后的时间和真实电量百分比；未同步时间显示 `--:--`，电量读取失败显示 `--%`。
- 电量不高于 15% 时提醒，回升到 20% 后解除低电量状态。
- 加入音量、亮度、设备信息、配网和重启菜单。
- 配网、激活和升级时隐藏气泡，用整屏完整显示热点、地址、验证码和进度文本。
- 保留原来音频、网络、唤醒词和服务器连接流程。

## 怎么操作

| 场景 | 按键 | 结果 |
| --- | --- | --- |
| 主界面 | 上键 / 下键 | 音量 +10 / -10，范围 0–100 |
| 主界面 | 确认短按 | 开始或停止对话 |
| 启动阶段 | 确认短按 | 沿用原版进入配网行为 |
| 待机 | 确认长按 | 打开设置菜单 |
| 设置菜单 | 上键 / 下键 | 切换选项 |
| 设置菜单 | 确认短按 | 打开选项 |
| 音量或亮度页 | 上键 / 下键 | 调整数值；亮度范围 10–100 |
| 选项页 | 确认短按 | 返回菜单；配网和重启页则执行已显示的确认操作 |
| 选项页 | 确认长按 | 返回菜单，取消尚未执行的配网或重启 |
| 设置菜单 | 确认长按 | 退出菜单 |
| 已息屏 | 任意键短按或确认长按 | 仅唤醒；下一次按键才执行功能 |

长按时间沿用现有按键组件的配置，不改 ADC 电压窗口或原板引脚。
菜单只允许在待机时打开。语音唤醒进入对话后自动收起菜单。

## 三分钟息屏规则

待机、等待连接或静默聆听时，连续 180 秒无操作后把背光降到 0，并暂停人物动画。
按键、识别到的语音活动、新的对话文本或设备状态变化会重新计时。
连续说话、播放回答、配网、激活、升级期间不自动息屏。
时间使用单调时钟，联网校时不会改变三分钟时长。

息屏不是关机或深度睡眠，音频流程和原有“你好小智”检测继续运行。
说唤醒词是否成功仍取决于原有模型、麦克风和实际环境。
背光关闭后不会持续显示睡眠页面；唤醒时恢复已保存的亮度。

## 电量的边界

CW2017 使用 `0x63` 地址，读取 `0x04/0x05` 的 SOC，复用 GPIO10/GPIO7 的 I2C 总线。
按芯片版本和配置寄存器做检查；必要时仅执行唤醒/重启序列，不写入未知电池参数。
电量最多每 15 秒重新读取一次。当前实现若开机未探测到电量计，需排查硬件后重启。

现有板卡资料没有确认充电状态引脚，因此此版本不实现“正在充电”页面，不伪造充电状态。
电量计需要适合实际电池的参数；本次没有获得或校准这些参数，实机上应与原固件读数比较。
低电量提示不代替硬件电池保护，也不会自动关机。

寄存器依据：[Cellwise CW2017 数据手册](https://uploadcdn.oneyac.com/upload/document/1737612108523_8373.pdf)，第 8、9、14 页。
绘图接口依据：[LVGL 9.5 官方示例](https://lvgl.io/docs/open/9.5/examples.html)。

## 怎样得到 BIN

源码包不是可以直接刷入的固件。项目已经包含 `.github/workflows/build.yml`，无需另写构建脚本。

1. 将解压后的项目文件放入你自己的 GitHub 仓库根目录，保留目录结构。不能只上传这个 ZIP，也不能多套一层项目文件夹。
2. 仓库根目录应直接有 `CMakeLists.txt`、`main/`、`scripts/` 和 `.github/`。
3. 在 GitHub 的 Actions 页面找到 `Build Folo AI Passport`，使用已有的手动构建入口，或向 `main` 分支提交触发构建。
4. 等构建成功后下载该次任务的固件产物，解压取得 `merged-binary.bin`。
5. 如果构建失败，保留完整日志供排查；不要把未编译源码或任意资源文件改名成 `.bin` 后刷入。

手机操作的具体页面可能因 GitHub 界面版本不同而变化；最重要的是完整上传目录和保留 `.github` 构建配置。
目前没有代你连接 GitHub、上传仓库或执行云端构建。

已有 ESP-IDF 的电脑可从项目根目录运行：

```sh
python scripts/build.py folo/ai-passport-c3 --name folo-ai-passport-c3 --language zh-CN --wake-word nihaoxiaozhi
```

烧录之前保留原固件与必要配置。完整合并镜像会覆盖原分区和运行数据，刷写方法见根目录 README。

## 已验证与待验证

已通过：`python -m unittest discover -s scripts/tests -v`，共 11 项。
亮度回归测试分别模拟 `int` 和 `long` 配置返回值，并检查负数、正常值及超过 255 的异常值，
防止模板类型推导冲突和转换为 `uint8_t` 时提前截断。
新增 C++ 主机测试使用 `-std=c++17 -Wall -Wextra -Werror` 编译真实的息屏策略、人物绘制头文件和电量驱动。
电量驱动使用模拟 I2C，不连接真实芯片。

覆盖内容：180 秒临界点、首次唤醒消费、语音活动、受保护状态、大时间戳、7 种表情的 336 帧绘图边界，
电量计地址/版本/唤醒序列、缓存、0% 和 100%、非法电量/电压、缺少设备和 I2C 错误恢复。
人物预览由固件同一绘图函数生成，但其中英文标签是预览说明，不是 LVGL 截图；实际固件使用中文。

未完成：当前环境无 `idf.py`，完整固件构建在检测 ESP-IDF 时停止，未产生 `.bin`。
主机测试不证明 LVGL、ESP-IDF 和全部依赖已成功编译链接，也不证明实际内存和帧率满足要求。
当前环境也没有 `clang-format`，尚未运行仓库指定的自动格式化器。

实机验收清单：

- 确认字体资源加载后中文完整显示，长回复和长热点名可以阅读。
- 连续切换菜单、调音量和亮度，无重启或卡死；菜单中的配网/重启取消行为正确。
- 静默等待约三分钟息屏，任意键第一次只唤醒；紧接着第二次按键正常执行。
- 刚开始变暗就立即唤醒，检查亮度不会继续降到 0。
- 息屏时说“你好小智”可按原有语音流程唤醒；长时间回答不误息屏。
- 配网、激活、升级期间屏幕保持可见。
- 电量显示与实际情况一致，拔插充电器后不出现虚构“充电”提示。
- 检查日志中的空闲内存，进行连续对话及长时间运行测试。

## 修改位置

- `main/boards/folo/ai-passport-c3/folo_display.*`：板卡专用 UI（全屏背景、气泡、多行滚动文字）。
- `main/boards/folo/ai-passport-c3/bg_shizue.c`、`bubble_bg.c`、`folo_images.h`：西施惠背景图与气泡图资源及其声明。
- `main/boards/folo/ai-passport-c3/assets_src/`：图片资源生成脚本 `gen_images.py` 与说明。
- `main/audio/background_music.{h}`、`background_music_player.{h,cc}`：背景音让路决策与循环播放。
- `main/assets/common/resident.ogg`：离线转码、增益 50% 的背景音。
- `screen_idle.h`：可在主机测试的息屏策略。
- `cw2017.h`：电量计接入。
- `folo_ai_passport_c3_board.cc`：按键、菜单和硬件连接。
- `main/display/display.h`、`main/application.cc`：语音活动通知。
- `main/boards/common/backlight.cc`：修复渐暗过程中唤醒未取消旧目标的问题。
- `scripts/tests/`：主机回归测试（息屏策略、电量驱动、背景音让路策略）。
